# 全库 Front V7 正式发布

正式更新 38,497 件真实资产的前向；2 个测试记录不变。V7 候选均通过输入和结果完整性检查；将其中已核实的 30 件视觉修正一并写入。Wishbone 椅的正面为资产局部 +Z。

水平主方向有语义前向 26,801 件，标准 +Z fallback 11,696 件；另保留多方向及竖直展示/使用面的独立标注。fallback 仅用于摆放，不算识别出的语义正面。

相对前一版，3,538 件主轴变化。主轴或语义标志变化关联的净空、操作空间和相对前向关系保留原数值并标记待重验；本次未重新计算这些几何约束。风格、主题色、材质、资产几何、物理参数及 Embedding 未改。

正式数据入口：`/data/task3_2/share_data/scenesmith/formal_current/annotations/`。版本见 `CURRENT_ANNOTATION_RELEASE.json`，逐件来源及旧版备份见发布目录。新进程直接读取本版；已缓存旧数据的长驻服务在重新加载标注后使用本版。

完整性通过不等于逐件语义正确。24 件全库随机样本的发布前 V7 主方向通过 22 件；定向抽检的高风险家具仍存在错误，不将本版描述成全库人工验收。
